# Sherwin Luis Morantte — Portfolio (Next.js)

A rebuild of sherwinluissss.github.io as a Next.js 14 (App Router) + Tailwind CSS site.

## Editing your content

Almost everything on the page — name, bio, skills, projects, contact info, social
links — lives in one file: `data/site.ts`. Edit that file and every section updates.

## Run it locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```
